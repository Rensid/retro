Проект для проведения ретро.

Проект должен включать в себя:

1) Пользователи

2) Комнаты или сервера, а может быть и то и другое

3) В каждую комнату инвайт только по ссылке. Ссылка будет либо одноразовая для каждого сотрудника отдельно, либо ограниченная по времени, чтобы сразу все сотрудники могли зайти по ней.

4) Внутри комнаты уже будет соответственно список участников.

5) При запуске каждый выбирает поле в котором он будет делать запись, оставляет ее и все соответственно аннонимно. Видно будет плашки записей, но сами записи видно не будет.
